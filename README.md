# adhd_timer adhd计时器

`adhd_timer` 是一款专为 ADHD（注意力缺陷多动障碍）群体、学生以及需要高度专注的人士设计的物理重力感应计时器。该应用基于 PWA（渐进式 Web 应用）技术构建，支持完全离线使用。它不仅利用了移动设备的陀螺仪和加速度传感器，还为桌面端用户提供了精美的 3D 物理仿真模拟器。

在日常生活中，操作手机设置倒计时本身就是一个极易让人分心的过程。`adhd_timer` 采用“无摩擦交互”设计理念，让你仅通过“翻转手机”这一个简单的物理动作，就能完成计时模式的选择、开始与暂停，从而将分心的可能性降到最低。

---

## 核心功能

### 1. 物理重力感应操作
* **倾斜选择模式**：将手机立起并向四个不同的方向倾斜，即可瞬间切换不同的预设专注/休息模式（如 25分钟番茄钟、5分钟短休、15分钟长休、自定义时长等）。
* **正面朝下即刻开始**：当决定开始专注时，只需将手机屏幕朝下扣在桌面上。计时器会自动触发震动反馈并开始倒计时。
* **正面朝上即刻暂停**：专注中途遇到紧急事情需要处理时，只需将手机屏幕重新朝上放置。计时器会发出轻柔的提示音并自动暂停，无需任何指尖的点击操作。

### 2. 3D 桌面仿真模拟器
* **无传感器设备的完美适配**：对于在电脑浏览器上使用，或设备本身不支持陀螺仪传感器的用户，应用提供了一个高颜值的 3D 虚拟手机模型。
* **交互式旋转**：通过鼠标拖拽旋转 3D 手机，或使用侧边栏的快捷按钮，可以无缝模拟手机在物理世界中的倾斜与翻转状态，同样能体验到重力计时的趣味与便利。

### 3. PWA (Progressive Web App) 支持
* **原生应用级体验**：支持在 iOS Safari、Android Chrome 或桌面端浏览器中一键“添加到主屏幕”，作为独立应用运行。
* **离线可用**：内置 Service Worker 动态缓存，无需连接互联网即可随时随地使用计时器及查看本地历史数据。

### 4. 专注历史与趋势统计
* **自动生成专注日志**：详细记录每一次专注的起止时间、时长、模式标签以及是否成功坚持完成。
* **可视化数据仪表盘**：直观的图表展示，帮助你回顾近期的专注趋势、每日累计专注时长以及不同模式的时间分配。

### 5. 高度自由的自定义设置
* **自定义时间与标签**：自由调整 4 个倾斜方向分别代表的倒计时时长与专注类型标签。
* **交互反馈设置**：支持自由开启或关闭倒计时结束时的音效提示，以及开始/结束时的设备振动反馈。
